Secure Workload Scope Planning Questionnaire

Your answers are used to design the scope tree for your Cisco Secure Workload tenant. A scope is a named group of workloads, and the scope tree is how those groups are arranged.

Answer what you know and leave out what you do not. The scope tree can be built in rounds: send what you have now, then add to your saved answers later and send them again.

This page works offline. Nothing you type is sent anywhere. Your answers stay on this computer until you save the answers file and send it to your Cisco contact.

4. How Your Environment Is Organized

Environments

Environments become the first level of the scope tree. Every server should belong to exactly one.

Sites And Clouds

List each data center and each cloud you run servers in.

Shared Services

Services that many applications depend on. Each one gets its own scope so one policy can cover access to it. Add the addresses if you know them. If you do not, leave them blank and add them in a later round.

5. Your Applications

Each application becomes a scope under its environment. If one application runs in two environments, add it once for each. List the applications you know today. Subnets, owner, and site can be left blank and added in a later round.

Column order: application, environment, owner, site or cloud, subnets. New environments and sites found here are added to section 4.
