CSW Scope Builder

Version 1.2, 19 Nov 2026. Supersedes 1.1. Every page and the helper carry this one version number.

Turns a customer's answers into a Cisco Secure Workload scope tree that follows Cisco's scope design principles. The customer runs everything that touches their tenant. You never need their login or API key.

Your Workflow

  1. Email the customer the three files under "Send To The Customer".
  2. The customer returns an answers file, and a scope list file if their tenant already has scopes.
  3. Open the planner and load those files. If you build under a scope that already stands for something, such as a Production scope, confirm that under "What The Parent Scope Stands For". Read the plan and clear any blockers with the customer.
  4. If the plan proposes a rename, a query change, or you want a scope removed, tick the box for each one you approve under "Changes To Existing Scopes". Nothing existing is changed without your tick and the customer's own go-ahead.
  5. Send the customer the plan as a PDF, the label file, and the plan file.
  6. The customer checks and uploads the label file, then builds the scopes.
